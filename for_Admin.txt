
1) для запуска бэкэнда и фронтэнда - command for Git Bush Here: в папке BIT в бэкэнде вызвать Git Bush Here, ввести комманду
mvn spring-boot:run

2) запуск тестов через терминал или cmd (входить через папку проекта) командой:
mvn clean test "-Dsurefire.suiteXmlFiles=src/test/resources/smokeTestsUI.xml"

3) как создать Allure для отчетов:
создать файл allure.properties

создать в src/test/resources/ папку META-INF/а также папку services/, а также файл org.testng.ITestNGListener
т.е. будет выглядеть так: src/test/resources/META-INF/services/org.testng.ITestNGListener

Потом запустить в терминале команду: mvn clean test
Появится в папке target  папка allure-results (т.е. target/allure-results)

!!! запуск тестов через терминал или cmd (входить через папку проекта) командой:
mvn clean test "-Dsurefire.suiteXmlFiles=src/test/resources/smokeTestsUI.xml"

!!! Потом ввести команду: mvn allure:serve
В гуглхроме откроется отчет:  Allure Report

!!! Потом ввести команду в терминале или cmd: mvn allure:report
Появится папка: target/site/allure-maven-plugin/
Там будет файл index.html. Навести курсором на правый верхний угол и появятся разные браузеры с отчетами
